# MATLAB Practice

A collection of MATLAB programs covering fundamental programming concepts, matrix operations, data visualization, control flow, loops, and user-defined functions. This repository documents my learning journey and serves as a reference for basic to intermediate MATLAB programming.

## Topics Covered

### MATLAB Basics

* Displaying messages
* Row and column vector creation
* Matrix creation
* Zero matrix
* Identity matrix

### Matrix Operations

* Matrix multiplication
* Element-wise multiplication
* Scalar addition
* Scalar multiplication
* Matrix transpose
* Squaring each element

### Matrix Indexing

* Extracting the first column
* Extracting the last column
* Using the colon operator

### Matrix Information

* Finding matrix size
* Finding total elements
* Matrix statistics

### Data Visualization

* Simple line plot
* Customized line plot
* Multiple line plots
* Scatter plot
* Bar chart
* Pie chart
* Subplots
* Multiple plots using `hold on`

### Programming Concepts

* Grade calculator (`if-elseif-else`)
* Even/Odd checker
* Largest of three numbers
* Menu-driven calculator (`switch`)
* Multiplication table (`for` loop)
* User-defined function
* Student marks analyzer

## Skills Demonstrated

* Variables and data types
* Vectors and matrices
* Matrix arithmetic
* Matrix indexing
* Built-in MATLAB functions
* Data visualization
* Conditional statements
* Looping constructs
* User-defined functions
* Basic data analysis

## Repository Structure

Each program is saved as an individual `.m` file with a descriptive filename for easy navigation and reference.

## Requirements

* MATLAB R2016b or later (recommended)

Most programs are compatible with earlier versions, except scripts containing local functions, which require MATLAB R2016b or newer.

## Learning Outcome

This repository demonstrates a strong foundation in MATLAB programming, including numerical computing, matrix manipulation, visualization, and problem-solving through practical examples.
